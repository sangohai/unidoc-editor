💾 核心工作记忆框架 (v2.0) - Emoji 密文盒 & WebRTC 生态

1. 项目代号与终极愿景
代号： Project Mirage (幻影 - 取其阅后即焚、无影无踪之意)
愿景： 打造一款基于 Android PWA 优先的“即用即走”免安装通信应用。融合“视觉艺术”与“密码学”，为用户提供一种兼具隐私安全与互动仪式感的新型社交体验。

3. 核心技术栈与架构设计
底层传输 (基础设施)： WebRTC (专注于 RTCDataChannel) + 极简 Node.js 信令服务器 + Coturn (用于付费级穿墙)。
呈现与存储载体 (革命性创新)： 采用 SVG (可缩放矢量图形)。SVG 既是面向用户的“视觉界面 (UI)”，同时也是隐藏加密数据的“密码容器 (Steganography)”。
应用形态： Web / Android PWA (利用 Web Share Target 实现系统级原生分享体验)。
商业模式： 免费档走 P2P (公共 STUN)；付费/捐赠用户下发专属 TURN 凭证保障 100% 连通率。长期目标是将 WebRTC 底层剥离为 BaaS 级 SDK。


5. 核心交互机制 (Killer Features)
卡片化隐写术： 将加密留言隐藏在 SVG 代码内部的 <metadata> 或自定义 data-* 属性中，外部只展示按特定几何排列的 Emoji 艺术图形。
P2P 极速投递： 密文 SVG 仅通过 WebRTC 点对点传输，服务器零留存，绝对隐私（物理级阅后即焚）。
交互式解密 (轻游戏化)： 结合 SVG 极易被 JS 操作 DOM (改变坐标、属性) 的特性，实现拖拽特定 Emoji 到指定位置等轻量级解密仪式，代替传统的输入密码。


7. 架构师避坑规则 (Rules)
[Rule 01] 坚决不使用 Canvas 作为交互画布，强依赖 SVG 的 DOM 特性来保证性能和低带宽传输。
[Rule 02] 不在前端硬编码 TURN 服务器凭证，严格采用后端临时签发 (REST API) 机制防盗刷。
[Rule 03] 接受 WebRTC 无法长期后台驻留的现实，产品交互必须设计为“明确触发、用完即走”。

💡 给你的几个灵感火花 (Brainstorming Sparks)

在你思考新玩法的时候，不妨顺着以下几个方向发散：

时空锁 (Geofence Lock)： 既然是 PWA，我们可以调用浏览器的地理位置 API。玩法：发送给对方的 Emoji 密文 SVG 带有坐标验证，“只有对方走到你指定的咖啡馆 50 米范围内，SVG 里的那扇门才会打开”。

视觉自毁机制 (Visual Self-Destruct)： 利用 SVG 天然支持 CSS 动画的特性。对方解密阅读 10 秒后，用 JS 触发一个类名切换，整个 SVG 卡片上的 Emoji 直接像粒子一样散开并溶解，不仅数据销毁，视觉上也彻底灰飞烟灭。

双人拼图解密 (Multi-party Interaction)： 发给两个不同的朋友各半个 SVG，他们必须在你的 WebRTC 房间里同时在线，把两块屏幕“拼”在一起，密文才会合并显现。
