# Blueprint: NeuroCanvas (LLM Topology & Spatial Editor)

### 🎯 1. 项目定位与当前状态
*   **项目名称**: NeuroCanvas (面向 LLM 的物理拓扑与空间关系编辑器)
*   **核心目标**: 构建一个极其轻量、纯前端的 2D 参数化建模工具（CAD-lite）。允许用户通过积木拼装或多段线绘制，建立具有层级关系、物理约束和语义标签的多边形图块集合，并最终输出结构化数据供 AI 消费。
*   **核心理念**: 践行“神经符号学”。为大语言模型（LLM）和生图模型（Stable Diffusion/ControlNet）提供精确的物理空间常识与遮挡关系，彻底跨越 AI 视觉生成的“像素盲区”。
*   **当前进度**: V0.1 架构图纸阶段完成。已彻底摒弃重型框架（Vue/React）；确立了底层 Proxy 状态机数据流向；完成了全英文 JSON Schema 数据结构设计；确定了“树形目录+绘图区”的双向联动布局。准备进入代码开发阶段。

### 🚦 3. 核心“黑科技”设计决策 (Design Decisions)
1.  **原生 Proxy 响应式中枢**: 抛弃虚拟 DOM 负重，几十行原生 Proxy 实现“改代码->刷画布”与“拖画布->刷代码/面板”的完美解耦。
2.  **正向运动学 (FK) 引擎**: 利用 Konva 的 `Group` 嵌套与 `offset` (枢轴) 属性，将树形目录的“UI 父子嵌套”在底层映射为“坐标系嵌套”。
3.  **无缝节点编辑模式**: 双击进入编辑态，动态在多边形顶点渲染高优先级 `draggable Circle`，实现 CAD 级的单点扭曲形变。
4.  **多模态同步输出**: 同时输出语义/约束 YAML 文本（供 LLM 逻辑推理）和深度特征图 PNG（供生图模型空间控制）。
5.  **防御性向后兼容**: 顶层设计 `version` 字段，读取数据强制使用后备默认值，确保历史模板永不崩溃。

### 🚀 4. 跨域开发计划 (Roadmap)
*   **[Phase 1] MVP 基础框架**: 搭建 HTML/CSS 骨架；打通 `stateManager.js` 与 `konvaEngine.js`，实现“画图->数据”闭环。
*   **[Phase 2] 交互与拓扑**: 实装状态机，完善多段线绘制；开发树形目录，实现拖拽图形建立父子关系及关节枢轴（Pivot）。
*   **[Phase 3] 编辑与参数**: 实现双击顶点编辑；完成属性面板的语义标签与旋转极限设置。
*   **[Phase 4] LLM 桥接**: 开发多模态导出；部署至 GitHub Pages，导入“17 关节人类手臂”，实测 GPT-4 提示词引导。
