# 项目名称：AegisAudio —— 零依赖原生架构的个人声学隐私护盾 (PWA MVP)

## 0. 项目伦理、合规与声学健康声明 (Ethics, Compliance & Health)
1. **防御型隐私保护定位 (Defensive Privacy Tool)：** 本项目是一个完全合法、合规的个人隐私保护与信息安全防御工具（性质等同于商业保密会议室常用的 Sound Masking 声学掩蔽系统）。其唯一目的是在用户设备周围产生温和的物理声学掩蔽场，防止潜在违规应用在后台利用麦克风进行未经授权的语音识别（ASR）窃听。
2. **严守浏览器沙盒边界：** 本项目 100% 运行在标准浏览器沙盒内，所有监测功能均基于标准 Web API 的自身状态反馈（如音频焦点被外部未知进程抢占导致的中断事件 `onmute`/`onended` 及本机声学回波分析）。
3. **听觉与神经健康保护原则 (Health-First Acoustics)：** 严禁输出高分贝高频刺耳噪音（禁止 >15kHz 的高能持续输出）。所有声学掩蔽必须采用符合人体工学的粉红噪音（Pink Noise）、褐噪音（Brown Noise）及自然呼吸节律调制（LFO），并在音频链路末端强制挂载动态压缩限幅器（`DynamicsCompressorNode`）以杜绝爆音。

## 2. 核心技术架构：No-Build 原生乐高模式 (Vanilla Lego Architecture)
本项目摒弃臃肿的 NPM、`node_modules` 和 Vite 等打包工具，采用浏览器原生支持的 **ES6 Modules (`<script type="module">`)** 构建。你必须严格遵守以下**五条代码铁律**：

1. **零构建依赖（Zero-Build & Vanilla JS）：** 所有代码均为浏览器可直接运行的原生 `.html`、`.css` 和 `.js`（ES6 模块）。UI 基础布局采用通过 CDN 引入的 **Bootstrap 5**，无需任何本地编译步骤。
2. **高内聚、零耦合（乐高积木原则）：** 每个功能模块必须是完全独立的 `.js` 文件（存放在 `js/modules/` 目录下）。模块之间**严禁直接互相引用**，只能通过主控制器 `js/app.js` 或统一的全局事件总线（`CustomEvent`）按照契约通信。
3. **使用现代 JSDoc 锁死接口契约：** 在每个 `.js` 文件顶部开启 `// @ts-check` 注释，并在 `js/core/contracts.js` 及各模块暴露函数处使用简洁标准的 **JSDoc (`@typedef`, `@param`, `@returns`)** 锁死数据类型。未经允许，严禁篡改契约。
4. **200 行体积紧箍咒与错误隔离：** 任何单个 `.js` 文件的代码行数**严格控制在 200 行以内**。每个模块的初始化与执行必须包裹在独立的 `try...catch` 沙盒中，确保单一模块报错绝不导致整体崩溃。
5. **轻量级标准 PWA：** 使用标准的 `manifest.json` 与极简稳定的原生 `sw.js`，确保离线可用且绝不产生缓存死锁。

## 3. 视觉与交互规范：OLED 极简黑白美学 (OLED Monochrome UI)
考虑到移动设备普遍使用 LED / OLED 屏幕，为实现极致节能与硬核安全仪表盘美学，视觉规范如下：
1. **纯黑节能底座：** 全局背景色强制锁定为 `#000000`（纯黑不发光），文字与线框仅使用 `#FFFFFF`（纯白）与 `#666666`（暗灰）。
2. **黑白线条水波/雷达扩散特效：** 当防护系统启动时，屏幕中央的 Canvas 模拟雷达圆心扩散或水波纹扩散效果。仅使用黑白细线条（`1px`）绘制，最大限度减少屏幕能耗。
3. **白色线框异常警告提示：** 当运行中侦测到有其他应用尝试访问/抢占麦克风时，弹出纯黑底色、**白色线框的长方形文字提示框**，内容格式为：`[时间 HH:MM:SS] 侦测到有设备/进程访问麦克风`；显示时长 **3~5 秒后自动消失**。
4. **假性息屏（潜行模式）的绝对静默：** 在进入“假性息屏”状态下，全屏纯黑（支持双击屏幕唤醒）。**在此状态下，上述雷达水波扩散特效、白色线框弹窗提示以及所有 UI 界面全部不显示（暂停 Canvas 渲染循环以彻底省电）**，仅在后台维持声学掩蔽与静默日志记录。

## 4. MVP 乐高模块拆解 (Lego Modules Breakdown)

### 底座与契约层 (`js/core/`)
- **`contracts.js`**：集中定义全局事件名、日志数据结构（`LogEntry`）及模块接口的 JSDoc 契约。
- **`audio-engine.js`**：管理全局唯一的 `AudioContext`，并在输出末端强制串联安全限幅器（`DynamicsCompressorNode`）。

### 积木一：健康声学掩蔽发生器 (`js/modules/acoustic-masker.js`)
- **功能：** 利用 Web Audio API 实时生成覆盖 300Hz-3400Hz 语音频段的健康掩蔽声波（支持切换“深海褐噪音 Brown Noise”、“春雨粉红噪音 Pink Noise”及“咖啡馆伪人声共振峰掩蔽 Formant Babble”），内置 LFO 呼吸调制。

### 积木二：麦克风占坑监测与抢占传感器 (`js/modules/mic-sensor.js`)
- **功能：** 开启低功耗麦克风音频流监听，严密监控 `MediaStreamTrack` 的 `onmute`、`onended`、音频焦点中断事件，以及利用 `AnalyserNode` 监控环境声学回波突变。一旦捕获异常，立即派发标准全局事件。

### 积木三：持久化安全日志查询系统 (`js/modules/log-manager.js`)
- **功能：** 监听积木二的异常信号，无论当前是否处于假性息屏，均立即将记录写入本地 `localStorage` / `IndexedDB`。提供黑白线框风格的日志查询面板，记录不同时间段自动访问/抢占麦克风的异常事件，支持按时间查询与清空。

### 积木四：OLED 水波纹雷达与线框弹窗 (`js/modules/oled-visualizer.js`)
- **功能：** 绘制黑白线条圆心水波纹扩散动画，并管理 3~5 秒自动消失的白色线框长方形警告提示。暴露 `setStealthMode(boolean)` 接口，在假息屏状态下彻底关闭特效与弹窗显示。

### 积木五：假性息屏节能锁 (`js/modules/stealth-lock.js`)
- **功能：** 调用 `Screen Wake Lock API` 防止系统休眠，开启全屏纯黑遮罩并通知积木四静默，监听双击屏幕（`dblclick` 及移动端双次触摸）唤醒界面。

### 积木六：ASR 语音识别验证台 (`js/modules/asr-tester.js`)
- **功能：** 调用原生 `SpeechRecognition` API，用于直观验证护盾开启后语音识别失效的效果。
